In this session, we will work on the following task:

- Write a new python script in the folder "agent/scripts" that will provide deterministic suggestions for the "Alternative journal name" column based on the ISSN of the journal. To do so, look for the journal that are either not "Present in Scimago", not "Present in DOAJ", not "Present in openAPC" and that have an ISSN (regardless of how this ISSN has been obtained). For those journals, look for the journal name that have the same ISSN in either the Scimago dataset, the DOAJ dataset or the OpenAPC dataset, and if there is a match based on ISSN, fill the "Alternative journal name" column with the journal name from this dataset (if there are several matches, use the Scimago dataset first, then the DOAJ dataset and finally the OpenAPC dataset). Make sure there is not already another "Alternative journal name", only fills thus that are empty. This script will write suggestion similar to the ones that the AI agent is writing, so that I can upload those suggestions to the Google sheet ("Agent_suggestions" tab), and later I can set them as "Accepted" and have them automatically uploaded to the field tabs by Google script, once I have reviewed them (and set them as "Accepted") in the "Agent_suggestions" tab. This way, I can have a deterministic way to fill the "Alternative journal name" column for the journals that are present in Scimago, DOAJ or OpenAPC, but for which the "Journal name" is not the one providing a match with the dataset. This will help me to fill the "Alternative journal name" column and match those journals with external sources during the enrichment step. These suggestions will have a confidence score of 1. Reuse as much as possible functions from the scripts "scripts/update_extracted.py" and "scripts/librairies.py (typically norm_name) of the WhereToPublish repository to avoid redundant code and to have a consistent codebase.
- Importantly, when uploading suggestions ("scripts/upload_sheets.py"), drop the duplicated suggestions for the same journal and suggestion (same column is filled) in the "Agent_suggestions.csv", to avoid having duplicates and confusion. If there are duplicates, only keep the one with the highest confidence score. You can use the script "scripts/upload_sheets.py" to upload suggestions to the Google sheet, but make sure to adapt it to check for duplicates before upload to the "Agent_suggestions" tab, and only keep the one with the highest confidence score for each journal and column.
